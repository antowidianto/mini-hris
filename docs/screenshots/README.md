# Screenshot Guide

Add product screenshots for portfolio or demo use in this folder.

Recommended captures:

- Login page
- Admin/HR dashboard
- Employee list and detail
- Company settings
- Contract monitoring
- Attendance report and monthly recap
- Leave request and approval queue
- Payroll list and detail
- Employee payslip
- Audit logs

Use filenames such as:

```txt
01-login.png
02-dashboard-admin.png
03-employee-list.png
04-payroll-detail.png
```
